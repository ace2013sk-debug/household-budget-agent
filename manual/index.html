01 · 구성

대시보드는 4개 화면입니다

1▦ 요약 보기총 지출·거래 건수·예산·사용률과 대분류·소분류 차트
2↗ 핵심 요약수입·지출·저축 추정과 월별 흐름
3◔ 월별 차트외식비+장보기, 지혜용돈, 성현용돈 월별 현황
4▤ RAW DATA동기화된 시트 원본 데이터와 요약 블록
왼쪽 사이드바의 메뉴를 누르면 화면이 바뀝니다. 아래쪽 「챗봇」 버튼으로 질문할 수 있습니다.
02 · 요약 보기

4개 지표로 한눈에 보기

총 지출선택 조건 기준 합계
거래 건수현재 월 기준
예산월별 계획 금액
사용률지출 ÷ 예산
📈 대분류별 지출도넛 차트와 예산 진행률 막대로 대분류 비중을 봅니다.
🔎 소분류별 지출표에서 행을 클릭하면 선택한 행의 합계가 표시됩니다.
03 · 필터

기간과 필터로 범위 좁히기

1연도25년 / 26년 버튼을 누릅니다.
2월1월~10월 버튼을 누릅니다. 11·12월은 데이터가 생기면 표시됩니다.
3구성원·분류상단 선택 상자에서 「전체」 또는 항목을 고릅니다.
🔄 지금 동기화오른쪽 위 버튼을 누르면 시트 데이터를 즉시 다시 불러옵니다.
04 · 핵심 요약

수입−지출로 저축 확인

상단 4개 카드추정 저축액 및 저축 비율 · 수입(월별 예산 기준) · 지출(월별 사용액) · 거래 건수
기간 버튼26년 1월~12월 중 월을 선택하고 구성원·분류도 고를 수 있습니다.
월별 구성원별 지출 흐름
생활비
부부
부부외
봄내
사업
구조 안내용 도식(수치 없음): 꺾은선 차트에 표시되는 5개 구분입니다. 오른쪽에는 수입 상세·지출 상세 도넛이 있습니다.
05 · 월별 차트

3개 항목의 월별 도넛

항목별 월 예산 (단위: 원)
1,000,000외식비+장보기
300,000지혜용돈
300,000성현용돈
값은 대시보드에 설정된 월 예산입니다.
상단 연도 버튼(25년·26년)으로 연도를 바꿉니다.
월마다 도넛이 표시되며, 예산 대비 사용 현황을 확인합니다.
06 · RAW DATA

원본 데이터 확인하기

1기간 선택연도·월 버튼을 누릅니다.
2표 읽기구분, 분류, 카드, 상세 내역, 금액, 예산 열을 확인합니다.
3페이지 이동표 아래 페이지 버튼으로 이동합니다.
4상태 표시오른쪽 위 「Google Sheets 자동 연동」 표시
요약 보기의 소분류 표에서는 행을 클릭해 여러 건의 합계를 바로 확인할 수 있습니다.

08 · 챗봇

챗봇에게 물어보세요

1열기사이드바 아래 「챗봇」 버튼을 누릅니다.
2질문 선택자주 하는 질문 10개 중 하나를 누르거나 직접 입력합니다.
3상세 페이지답변의 「상세 페이지」 버튼으로 이 매뉴얼의 해당 쪽을 엽니다.
4이동·크기제목 줄을 끌어 이동, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다.
궁금한 건 챗봇에게!
